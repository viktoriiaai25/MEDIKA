# МЕДИКА — Digital Medical Skills Trainer

Готовая статическая веб-версия приложения «МЕДИКА» для публикации через GitHub Pages.

## Что внутри
- 4 специальности
- 54 практических навыка
- чек-листы и режим тренировки
- тесты по навыкам
- результаты и история
- поиск
- ссылки на материалы ФМЗА
- мобильная адаптация
- зелёно-белый медицинский интерфейс

## Публикация
1. Создайте публичный репозиторий, например `medika`.
2. Загрузите **содержимое этой папки**, чтобы `index.html` находился в корне репозитория.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. После публикации адрес будет вида `https://ВАШ-ЛОГИН.github.io/medika/`.

Файл `.nojekyll` уже добавлен.
